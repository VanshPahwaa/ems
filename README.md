# 🏢 Employee Management System (EMS)

A clean and responsive task management web app built with **React** and **Tailwind CSS**. It features role-based access for Admins to assign tasks and Employees to manage their daily work.

---

## 🚀 Features

- **Role-Based Access:** Dedicated dashboards for Admin and Employees.
- **Admin Dashboard:**
  - Create and assign tasks with titles, categories, and due dates.
  - Real-time team overview tracking New, Active, Completed, and Failed tasks.
- **Employee Dashboard:**
  - Personalized stats counter for assigned work.
  - Interactive task board displaying current and past assignments.
- **Local Persistence:** Data is stored and updated via browser `localStorage`.

---

## 🛠️ Tech Stack

- **React 19**
- **Tailwind CSS v4**
- **Vite**

## 💻 Getting Started

### 1. Clone & Install

```bash
git clone https://github.com/VanshPahwaa/ems.git
cd ems
npm install
```

### 2. Run the App

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.
